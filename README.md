# Vishnu D — Premium Engineering Portfolio

A responsive, cinematic portfolio built with semantic HTML, modern CSS and lightweight JavaScript. No framework or build step is required.

## Run locally

Open `index.html` directly, or run a static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

Upload the project folder to GitHub Pages, Netlify, Vercel or any static hosting service.

## Structure

- `index.html` — semantic content and metadata
- `style.css` — responsive visual system and motion
- `script.js` — navigation, scroll reveals, active states and 3D tilt
- `assets/profile-photo.jpg` — original supplied profile photograph
- `assets/favicon.svg` — portfolio favicon

## Accessibility and performance

The site includes keyboard focus states, a skip link, semantic landmarks, meaningful alternative text, responsive layouts and reduced-motion support. All visual effects are local and dependency-free.
